## 📂 Contenido del Repositorio

Este repositorio está estructurado como una página web estática (`index.html`) que funciona como un "Hub" o visor central para abrir los diferentes proyectos técnicos sin salir de la página principal.

### 📄 Archivos Principales
* `index.html`: La página principal del portafolio interactivo (CV, Habilidades, Experiencia y Visor de Proyectos).
* `Kevin_Gomez_CV_DataEngineer.pdf`: Mi currículum vitae en formato PDF, listo para descarga directa.
* `FotoPortadaCV.png` / `FotoPortadaCV.jpg`: Fotografía de perfil utilizada en la interfaz web.

### 🛠️ Casos de Estudio Técnico (Proyectos ETL)
Estos archivos HTML contienen documentación profunda, paso a paso, de implementaciones reales utilizando **Informatica PowerCenter** y **Oracle SQL**:

1. 🔍 **`data_engineer_portfolio_story.html`**:
   * **Tema:** Lookup Transformation, Cachés (Static/Dynamic) y enriquecimiento dimensional.
   * **Descripción:** Integración de fuentes relacionales heterogéneas implementando buenas prácticas de modelado de base de datos.
2. 🗂️ **`caso_de_estudio_etl_union_rank.html`**:
   * **Tema:** UNION Transformation, Depuración de Duplicados (Sorter Distinct) y jerarquización (Rank TR / Top-N).
   * **Descripción:** Consolidación multifuente y comparación técnica con Set Operators en SQL (UNION vs UNION ALL).
3. 📁 **`caso_de_estudio_flat_files.html`**:
   * **Tema:** Gestión Avanzada de Archivos Planos (Flat Files).
   * **Descripción:** Arquitecturas *File-to-DB*, *DB-to-File* y *File-to-File*. Configuración de delimitadores, ancho fijo y enrutamiento con variables de servidor (`$PMSourceFileDir`).
4. 📘 **`apuntes_informatica_powercenter.html`**:
   * **Tema:** Cheat Sheet Técnica.
   * **Descripción:** Guía rápida y notas de apoyo para troubleshooting (ej. Error FR_3000), configuraciones de servidor y arquitectura básica de la herramienta ETL.
